# 신영수 스튜디오 (SHIN YOUNG SOO Studio)

전주 웨딩스냅, 본식스냅, 웨딩스튜디오 - 신영수 스튜디오 공식 웹사이트

## 프로젝트 소개

신영수 스튜디오의 포트폴리오 및 갤러리를 보여주는 웹사이트입니다.

### 주요 기능

- 📸 **갤러리 필터링**: 카테고리별 사진 필터링 (Wedding Ceremony, PreWedding, Body Profile, Profile, Hanbok 등)
- 🎨 **반응형 디자인**: 모바일, 태블릿, 데스크톱 모든 기기 지원
- ✨ **우아한 UI/UX**: Playfair Display와 Lato 폰트를 사용한 세련된 디자인
- 🖼️ **Masonry 레이아웃**: 다양한 사이즈의 이미지를 자연스럽게 배치

## 기술 스택

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Fonts**: Google Fonts (Playfair Display, Lato)

## 시작하기

### 필수 요구사항

- Node.js 18.17 이상
- npm, yarn, pnpm 또는 bun

### 설치 및 실행

1. 의존성 설치:
```bash
npm install
```

2. 개발 서버 실행:
```bash
npm run dev
```

3. 브라우저에서 [http://localhost:3000](http://localhost:3000) 열기

### 빌드

프로덕션 빌드:
```bash
npm run build
npm start
```

## 프로젝트 구조

```
├── app/
│   ├── layout.tsx      # 루트 레이아웃 (폰트 설정)
│   ├── page.tsx        # 메인 갤러리 페이지
│   └── globals.css     # 글로벌 스타일
├── public/             # 정적 파일
└── package.json
```
